# Sorting

```
* shell sort - gap / 2, compare elements in gap
* tree sort - construct bst, inorder traversal
* Comb sort - shell sort, gap/1.3
* pegion hole sort - similar to counting sort, but count close to 1
    * cal max,min, range = max-min+1, new array of size range, traverse, put element in New[A[i]-min]

Adv of BST over Hashing
* We can get all keys in sorted order by just doing Inorder Traversal of BST. This is not a natural operation in Hash Tables and requires extra efforts.
* Doing order statistics, finding closest lower and greater elements, doing range queries are easy to do with BSTs. Like sorting, these operations are not a natural operation with Hash Tables.
* BSTs are easy to implement compared to hashing, we can easily implement our own customized BST. To implement Hashing, we generally rely on libraries provided by programming languages.
* With Self-Balancing BSTs, all operations are guaranteed to work in O(Logn) time. But with Hashing, Θ(1) is average time and some particular operations may be costly, especially when table resizing happens.

```

# Singly Link List

## Basics

Node has pointer that points to next node Head points to first node Last node's next pointer points to NULL

### Advantages

- Dynamic Size, Runtime allocation in Heap, Efficient memory use
- Insertion/Deletion Easy

### Disadvantages

- No random access
- Extra space for pointers
- Not chache friendly

1. Make head global : Not recommended due to security
2. Function returns head : Calling function assign it as head
3. Pass reference to head pointer = Double Pointer : Node **head

### Huffman Tree

```
BUILD FROM UNSORTED ARRAY - O(nlogn)
    Build min heap of leaf according to frequency
    Pop pq (left child), Pop pq (right child), Insert root into pq with freq = sum of left+right

    Pop 2 min from q1/q2 and insert into q2
    Repeat till only one left
```

# Binomial Tree

B(k) = B(k-1) as left child of root of B(k-1) B(0) = 1 node

Properties of B(k)

1. It has exactly 2^k nodes.
2. It has depth as k.
3. There are exactly kCi nodes at depth i for i = 0, 1, . . . , k.
4. The root has degree k and children of root are themselves Binomial Trees with order k-1, k-2,.. 0 from left to right.

# Binomial Heap

Collection of Binomial Trees, which follow min heap property Binomial heap of n nodes = Binary conversion of n shows existence of that Binomial Tree n = 2^p + 2^q + 2^r then Heap has B(p),B(q),B(r) No 2 binomial tree of same order can exist

```
Operation

Union of 2 binomial heaps = Similar to binary addition
if b(k) then do nothing
if b(k),b(k) then combine them to form b(k+1) [like 1+1 = 10]
if b(k),b(k),b(k) then leave one and combine other to form b(k+1),b(k) [like 1+1+1 = 11]

Other operations works like in heap, but calls union operation if required

```
