public int[] findRedundantConnection(int[][] edges) {
    int[] parent = new int[2001];
    for (int i = 0; i < parent.length; i++) parent[i] = i;

    for (int[] edge: edges){
        int f = edge[0], t = edge[1];
        if (find(parent, f) == find(parent, t)) return edge;

private int find(int[] parent, int f) {

## Max-Flow-from-S-to-T-MEDIUM

| O(VE) | O(E) |
| --- | --- |

```
Ford-Fulkerson Algorithm
    While there is a augmenting path from source to sink Add this path-flow to flow.

bfs(r[][], start, end, p[])
    visited[start] = true
    p[start] = -1
    q = start
    while q not empty
        s = q.pop
        for all vertices : i
            if !visited[i] && r[s][v] > 0
                visited[i] = true
                p[i] = s
                q.push(i)
    return visited[end]

solve(g[][],s,t)
    r[][] = g
    p[] : parent array
    while bfs(r, s, t, p)
        flow = min of path from s to t using p[]
        for (v=t; v != s; v=p[v])
            u = p[v]
            r[u][v] -= flow
            r[v][u] += flow     // Added in Reverse Path - IMP
        ans += flow
    return ans

```
