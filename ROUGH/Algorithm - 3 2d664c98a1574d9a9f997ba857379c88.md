## Z Algorithm

Z[k] = length of prefix of string common with prefix of string starting from k

```
string = pattern + $ + text

z[n] = 0
l = r = 0
loop k : 1 to len-1
    if k > r
        l = r = k
        while r < len && s[r] == s[r-l]
            r++
        z[k] = r-l
        r--
    else
        if z[k-l] < r - k + 1
            z[k] = z[k-l]
        else
            l = k

## Manester Algorithm

```
string ss = # + s[0] + # + s[1] + ... s[len-1] + #

n = ss.len
p[n] = 0
c = r = ml = 0
loop i : 0 to n
    m = 2*c - i
    if i < r
        p[i] = min(r-i, p[m])
    a = i+1+p[i]
    b = i-1-p[i]
    while a < n && b >= 0 && ss[a] == ss[b]
        a++, b--, p[i]++
    if i+p[i] > r
        c = i, r = i+p[i]
        ml = max(ml,p[i])
